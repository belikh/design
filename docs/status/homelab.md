# Status: home lab, household, quality

Code in `apps/admin/src/areas/homelab/`, styles in `homelab.css`. Sample data uses a fixed clock (`TODAY` = 2026-11-12) so output is deterministic. There is no backend: every table is an in-memory `createCollection` (one per key, kept for the session) read through `useCollection`, so in-place edits, bulk edit, add-row, optimistic save, offline queue and `SyncStatus` all work. Pure logic lives in `*.data.ts` and is covered by the `*.test.tsx` files beside it.
