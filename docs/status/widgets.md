# P3 status: area c (inputs, drawing, media, collaboration)

Code in `apps/admin/src/p2/p3c/`, routes under `/p3/*` (nav groups **Grids**, **Inputs (specialised)**, **Collaboration**).
Mostly simulated locally: no network, no real model, no real bot protection. The exceptions are C042, C043 and C048, which use real browser APIs (MediaRecorder, Web Audio, video and canvas, FontFace) entirely in the tab. Pure logic is in `.ts` modules with unit tests
(`formula`, `schedule`, `colour`, `audio`, `video`, `fonts`, `query`, `geometry`, `ink`, `feedback`, `confirm`, `collab`, `chatsim`); components are in `*.tsx`
and tested in `components.test.tsx`. Every entry is labelled with its ID in its panel heading.

## Checks
- `npx tsc -b --noEmit`: no errors in this folder.
- `npx vitest run src/p2/p3c`: unit and component tests. New pure-logic suites: `colour-hsv.test.ts` (HSV/HSL/RGB conversion, alpha hex, rgb() parsing), `audio.test.ts` (peaks, trim maths, WAV encode/parse/round trip, tone, video frame scoring), `fonts.test.ts` (catalogue, installed-font detection, FontFace availability). `media-real.test.tsx` covers the pad keyboard, sync, EyeDropper feature check, font availability, the live recorder flow with a mocked MediaRecorder and devices, decoded-audio trimming and WAV export with a mocked AudioContext.
- `npm run e2e:media -w apps/admin` (or `E2E_URL=http://127.0.0.1:3000 node scripts/e2e-media.mjs`): real Chromium (`/usr/bin/chromium`) launched with `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream --autoplay-policy=no-user-gesture-required`, plus `--disable-audio-output` (keeps the Web Audio clock running without a sound card) and a generated tone as the fake microphone. It records from the fake microphone (meter moves, pause freezes the timer), plays the clip back, decodes it, trims, exports a WAV and checks its RIFF header and duration (and that the browser can decode it); trims a known 440 Hz WAV and checks peaks, frame count and amplitude; generates a webm video, loads it, checks duration, 12 thumbnails that really differ, keyboard scrubbing, cover choice and a native-size PNG; records from the fake camera and uses that clip; checks the denial path falls back to simulated only explicitly; runs axe on the loaded states.
- `src/test/a11y` and `src/routes.test.tsx` pass for all 13 `/p3/*` routes of this area; the a11y baseline is untouched.
- `npm run lint:style`: no new violations (sample colour data lives in `palette-data.ts`).
- jsdom prints "Not implemented: HTMLCanvasElement getContext" for the canvas demos and the font picker's system-font probe; the code guards for a missing context.
