# Contributing

Thanks for considering contributing to this project. It's a personal design
system, so I'm not actively looking for contributors — but if you want to fix
a typo, borrow an idea, or send a pull request, go right ahead.

## How to contribute

1. Fork the repo and create a branch for your change.
2. Make your change. Keep it small and focused.
3. Open a pull request. Describe what you changed and why.
4. I'll review when I can — I work a full-time job, so it might take a while.

## What I'm looking for

- Bug fixes and typo corrections
- Documentation improvements
- Small, self-contained features

## What I'm not looking for

- Large new features that change the direction of the project
- Dependencies that add maintenance burden
- Breaking changes without a very good reason

## Code style

Follow the existing conventions in the repo. Tokens only — no hard-coded
colours, font sizes or pixel values. Australian English spelling in prose.

## Conduct

Please be kind and respectful. This project follows the Contributor Covenant
code of conduct. See CODE_OF_CONDUCT.md.
