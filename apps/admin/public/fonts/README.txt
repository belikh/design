Jupiter design system - fonts/
Place this folder next to jupiter.css. jupiter.css references fonts/<file>.woff2 and
falls back to system fonts when a file is missing.

(.pfb + .afm) to WOFF2 with kerning. Marked "confidential and proprietary" by Bitstream:
